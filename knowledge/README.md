# База знаний

Здесь появляются только реальные знания, которые понадобятся повторно: карта экспертности, данные о клиентах, продуктовые решения, результаты проверок, продажи и процессы.

Перед созданием файла агент проверяет, нет ли уже подходящего. Пустые шаблоны и дубли не создавать.

Markdown является источником истины. HTML можно создавать рядом только как удобное представление конкретного Markdown-файла.
