# Мой продукт — учебная фикстура
Все люди и факты ниже вымышлены для проверки агента.
Олег изучил автоматизацию и выбрал AI-гипотезу: помощник владельца маленькой студии йоги, который из обезличенной выгрузки посещений в CSV вручную с участием Олега готовит черновой список клиентов, у которых скоро заканчивается абонемент, и черновики персональных напоминаний. Студия сама проверяет и отправляет сообщения. Сегмент: один владелец, один филиал, 40–100 клиентов.
Пока есть только локальный набросок процесса на синтетических данных. Нет приложения, сервера, интеграции с CRM, авторизации, оплаты, договорённого API, демонстрации на реальном клиенте и подтверждённых продаж. Нельзя называть это работающей SaaS-платформой. Точность, цена, сроки, стоимость API и поддержки не измерены.
Границы предполагаемой пробы: одна обезличенная выгрузка до 100 строк, человек проверяет вывод, нет автоматических рассылок и обещания роста продлений. Ресурсы: 5 часов в неделю; один знакомый владелец студии готов посмотреть демонстрацию, но не соглашался платить. На рекламу и разработчика денег не выделено.
Олег думает сделать бесплатный универсальный сборник «100 промптов для школьников», но открыт к другой идее. Хочет понять, чем могут отличаться проба, платный пилот, внедрение и сопровождение, и что проверять первым. Всё новое пока гипотеза. Никаких внешних действий, покупки API и загрузки реальных персональных данных.
